# About

**marginalia** is a notebook of small lessons from everyday software engineering.
Each lesson takes one question I ran into at work, explains it in plain words,
lets you try it in a runnable demo, and asks how AI is changing the answer.

Medieval scribes wrote in the margins of the books they copied: corrections,
questions, small drawings. This is my margin.

## House rules

1. **Ideas, not workplaces.** Lessons are general questions. They never name an
   employer, client, internal system or colleague.
2. **One question per lesson.** A reader should finish it in about ten minutes.
3. **Runnable, forever.** Every demo is a single HTML file with no build step,
   no accounts and no API keys. An automatic check opens every demo on each change.
4. **Sourced.** Every factual claim links to a public source. Vendor statistics are
   labelled as vendor statistics.
5. **Under AI.** Every lesson ends with how the topic is changing because of AI.
   *Now* holds dated, sourced facts. *Next* holds predictions, labelled as opinion,
   so they can be checked later.
6. **Public-domain art.** One credited CC0 or public-domain artwork per lesson.

## Anatomy of a lesson

```
lessons/NNN-slug/
  README.md   the lesson
  demo/       a single-file demo you can run locally
  figures/    hand-made SVG diagrams, only where a picture beats a paragraph
  art/        one public-domain artwork and its credit
```

Sections: artwork and epigraph · in short · the question · the lesson · the demo ·
under AI (now / next) · sources.
